## 虚短虚断（理想运放）
关键词：虚短、虚断、理想运放、线性区、开环增益、负反馈、差模输入
公式：虚短 v_p - v_n = v_o / A_vo ≈ 0，即 v_p ≈ v_n；虚断 i_I = (v_p - v_n) / r_i ≈ 0，即 i_p = -i_n ≈ 0
解释：开环电压增益 A_vo → ∞ 且输出电压 v_o 为有限值，故差模输入 v_p - v_n = v_o / A_vo ≈ 0，两输入端近似短路，称"虚短"；输入电阻 r_i → ∞ 且 v_p - v_n ≈ 0，故输入电流 i_I = (v_p - v_n) / r_i ≈ 0，称"虚断"
条件：运放工作在线性区（电路必须引入负反馈）；理想化条件 A_vo → ∞、r_i → ∞、r_o → 0、开环带宽 BW → ∞
来源：教材 2.2 理想运算放大器（P21-22）

## 反相比例运算电路
关键词：反相放大、比例运算、虚地、电压增益、负反馈
公式：A_v = v_o/v_i = -R_2/R_1；当 R_2 = R_1 时 v_o = -v_i
解释：输入经 R_1 加到反相端，R_2 跨接输出端与反相端构成负反馈，同相端接地。由虚短得 v_N ≈ v_P = 0，反相端为"虚地"，故 v_i/R_1 = -v_o/R_2，解得 v_o = -(R_2/R_1)v_i，负号表反相
条件：理想运放（虚短虚断），闭环负反馈
来源：教材 2.3.2 反相放大电路（P26）

## 同相比例运算电路
关键词：同相放大、比例运算、电压增益、负反馈、电压跟随器
公式：A_v = v_o/v_i = 1 + R_2/R_1（恒 ≥ 1，同相）；R_2 = 0 时 A_v = 1（电压跟随器）
解释：输入加到同相端，R_1 从反相端接地、R_2 跨接输出端与反相端构成负反馈。由虚短 v_N ≈ v_P = v_i，得 v_o = (1 + R_2/R_1)v_i，输出与输入同相
条件：理想运放（虚短虚断），闭环负反馈
来源：教材 2.3.1 同相放大电路（P23）

## 求和运算电路（反相加法器）
关键词：求和、加法、多输入、比例运算、虚地
公式：-v_o = (R_3/R_1)v_i1 + (R_3/R_2)v_i2；当 R_1 = R_2 = R_3 时 -v_o = v_i1 + v_i2
解释：多路输入经各自电阻 R_1、R_2 接到反相端，R_3 为反馈电阻。由虚地 v_N = 0，节点电流 i_1 + i_2 = i_3，即 v_i1/R_1 + v_i2/R_2 = -v_o/R_3，输出为各输入加权求和（反相）
条件：理想运放（虚短虚断），闭环负反馈
来源：教材 2.4.3 求和电路（P32）

## 积分运算电路
关键词：积分、运算电路、时间常数、反馈电容、阶跃响应
公式：v_o = -(1/RC)∫v_i dt；阶跃输入时 v_o ≈ -(V_i/RC)·t = -(V_i/τ)·t（τ = RC）
解释：输入经 R 加到反相端，电容 C 跨接输出端与反相端作反馈元件。由虚断 i_R = i_C，v_o = -v_C = -(1/C)∫i_C dt = -(1/RC)∫v_i dt，输出为输入的积分
条件：理想运放（虚短虚断），闭环负反馈
来源：教材 2.4.4 积分电路（P33）

## 微分运算电路
关键词：微分、运算电路、时间常数、反馈电阻、高频噪声
公式：v_o = -RC·(dv_i/dt)
解释：与积分电路互换 R、C 位置——电容 C 串在输入回路、电阻 R 作反馈元件。由虚断 i_C = i_R，i_C = C·dv_i/dt，故 v_o = -i_R·R = -RC·dv_i/dt，输出为输入的微分
条件：理想运放（虚短虚断），闭环负反馈
来源：教材 2.4.4 微分电路（P34-35）

## 负反馈四种组态判断
关键词：负反馈、组态、电压反馈、电流反馈、串联反馈、并联反馈、输出短路法、瞬时极性法
公式：四种组态 = 电压串联、电压并联、电流串联、电流并联；电压串联反馈系数 F_v = v_f/v_o = R_1/(R_1+R_f)；电压并联互导反馈系数 F_g = i_f/v_o ≈ -1/R_f
解释：输出端取样方式用"输出短路法"判断——令 v_o = 0（负载短路），若反馈信号消失则为电压反馈（取样输出电压），若反馈信号仍在则为电流反馈（取样输出电流）。输入端叠加方式判断——反馈信号与输入信号以电压形式叠加（接基本放大电路不同输入端）为串联反馈，净输入 v_id = v_i - v_f；以电流形式叠加（同一节点）为并联反馈，净输入 i_id = i_i - i_f。反馈极性用"瞬时极性法"判断：设 v_i 瞬时为正，看反馈使净输入增大（正反馈）还是减小（负反馈）
条件：闭环负反馈放大电路
来源：教材 8.1.6 负反馈放大电路的四种组态（P355-356）

## 深度负反馈近似计算
关键词：深度负反馈、闭环增益、反馈深度、环路增益、虚短、虚断、反馈系数
公式：闭环增益 A_f = A/(1+AF)；深度负反馈（|1+AF| ≫ 1）时 A_f ≈ 1/F
解释：负反馈放大电路闭环增益一般表达式 A_f = A/(1+AF)，其中 A 为开环增益、F 为反馈系数、1+AF 为反馈深度（AF 为环路增益）。|1+AF| > 1 为负反馈（增益下降）、< 1 为正反馈（增益上升）、= 0 为自激振荡。深度负反馈时反馈信号与输入信号相差甚微 x_i ≈ x_f，净输入 x_id = x_i - x_f ≈ 0，即 v_id ≈ 0（虚短）与 i_id ≈ 0（虚断）同时存在，闭环增益只由反馈网络（1/F）决定，与开环增益 A 基本无关
条件：|1+AF| ≫ 1（深度负反馈）
来源：教材 8.2 增益的一般表达式（P360）、8.4 深度负反馈（P371）
