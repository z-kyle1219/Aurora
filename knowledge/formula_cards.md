## 虚短虚断（理想运放）
关键词：虚短、虚断、理想运放、线性区、开环增益、负反馈、差模输入
公式：虚短 v_p - v_n = v_o / A_vo ≈ 0，即 v_p ≈ v_n；虚断 i_I = (v_p - v_n) / r_i ≈ 0，即 i_p = -i_n ≈ 0
解释：开环电压增益 A_vo → ∞ 且输出电压 v_o 为有限值，故差模输入 v_p - v_n = v_o / A_vo ≈ 0，两输入端近似短路，称"虚短"；输入电阻 r_i → ∞ 且 v_p - v_n ≈ 0，故输入电流 i_I = (v_p - v_n) / r_i ≈ 0，称"虚断"
条件：运放工作在线性区（电路必须引入负反馈）；理想化条件 A_vo → ∞、r_i → ∞、r_o → 0、开环带宽 BW → ∞
来源：教材 2.2 理想运算放大器（P21-22）
